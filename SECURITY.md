# Report a security issue

Use GitHub's private **Report a vulnerability** button under the repository's Security tab when enabled. If unavailable, open an issue requesting a private contact channel and wait for a maintainer response before sharing sensitive details. Include the affected commit, platform, component and impact. Redact video links, addresses, QR data, peer credentials and local paths.

The master branch is under development. No signed release or independently audited version is available. An exposed pairing QR expires after 90 seconds. Revoke an affected computer on the phone, then forget the device in the extension.

Maintainers assess reports against the [threat model](docs/THREAT_MODEL.md), coordinate disclosure with the reporter and publish a fix and advisory when appropriate. See [release controls](docs/RELEASE.md) for owner-managed settings.
