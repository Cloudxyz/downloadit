# Privacy

Download IT uses local preferences and local job history. Requested retrieval contacts YouTube for public video information and Google Video for media. Those providers receive the network address and requested resource. The design excludes browsing history, cookies, analytics, advertising and credential collection.

Build tools contact package registries. Release checks and installation are separate from runtime. Removing application data clears local preferences and job history. Media already published belongs to the user.

Optional MP3 artwork requests one JPEG from i.ytimg.com for the selected video. QR scanning uses camera frames locally. Paired operation sends job IDs, profiles and status to the selected private Wi-Fi endpoint over authenticated TLS. The user can revoke peer access and clear completed job records.
