# Contributing

Read [AGENTS.md](AGENTS.md), [the architecture](docs/ARCHITECTURE.md) and [the threat model](docs/THREAT_MODEL.md). Keep source and documentation in English. Update English and Spanish UI together.

Install the versions in [installation](docs/INSTALLATION.md). Run the relevant pnpm checks before proposing a focused change. Explain how you validated it, what needs a physical device and whether a boundary or permission changed. Record implementation status in the same change. Use native runtime validators and update the wire schema alongside the implementation.

For dependencies include the exact version, provenance, license, purpose and lockfile changes. For executable assets include signature and checksum verification. Retain third-party license text. Keep credentials, downloaded media and build products out of Git. Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
