# Download IT

Download authorized YouTube media from Brave on Windows and Android. Download IT is an independent open-source project. Use it only when you have permission from the rights holder and the service to obtain the media.

See [implementation status](docs/PROJECT_STATUS.md), [architecture](docs/ARCHITECTURE.md), [privacy](docs/PRIVACY.md) and the [threat model](docs/THREAT_MODEL.md).

Development requires Node 24.13.0 and pnpm 11.1.1. Run `pnpm install --frozen-lockfile --ignore-scripts`, `pnpm typecheck`, `pnpm lint` and `pnpm build`.
